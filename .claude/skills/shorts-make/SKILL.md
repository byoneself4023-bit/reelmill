# 쇼츠 한 편 만들기

각 단계의 실제 규칙은 단계 스킬에 있다. **이 스킬은 순서와 멈추는 곳만 정한다.** 단계에 들어갈 때마다 그 스킬의 SKILL.md 를 읽고 그대로 따른다.

| 단계 | 따를 스킬 | 결과물 |
|---|---|---|
| 1 대본 | `.claude/skills/shorts-script/SKILL.md` | script.md |
| 2 나레이션 | `.claude/skills/shorts-narration/SKILL.md` | narration.mp3 |
| 3 문장 시각 | `.claude/skills/groq-timing/SKILL.md` | sentences.json |
| 4 스타일 시안 | `.claude/skills/shorts-style-drafts/SKILL.md` | drafts/ (chosen) |
| 5 조립·렌더 | `.claude/skills/shorts-render/SKILL.md` | video.mp4 |

## 부르는 법

```
/shorts-make 올림픽 금메달에 진짜 금은 얼마나 들어 있을까 1분
/shorts-make 스포츠                 ← 분야만 주면 1단계에서 제목 15개부터
/shorts-make gold-medal             ← 이미 있는 에피소드 폴더 이름이면 이어서 하기
```

입력에 다음 말이 있으면 해당 멈춤을 건너뛴다(사용자가 미리 허락한 것으로 본다):
- 길이(「30초」「1분」「90초」「2분」「3분」) → 1단계 길이 묻기 생략
- 「생성까지 해도 돼」「크레딧 써도 돼」 → 2단계 생성 허락 생략
- 「스타일은 맡길게」 → 4단계에서 내가 추천 1순위를 고르고 비교판은 결과로만 보여 준다

## 0. 시작 점검 (멈추지 않음, 모자라면 멈춤)

```bash
uv run .claude/skills/shorts-make/scripts/status.py [work/episodes/<폴더>]
```

- 준비물(uv · ffmpeg · node · Remotion 작업실 · .env 키 3개)에 ✗ 가 있으면 무엇이 빠졌는지와 노션 「준비」의 어느 부분을 보면 되는지 알려 주고 멈춘다. 키 값은 묻거나 찍지 않는다.
- 에피소드 폴더가 이미 있으면 「다음: N단계」부터 이어서 한다. 앞 단계를 다시 하라는 말이 없으면 다 된 단계는 건너뛴다. 1단계를 다시 하면 그 뒤 단계(2~5)도 모두 다시 한다.

## 멈추는 곳 (이 네 곳뿐)

| 언제 | 왜 | 사용자 답 예 |
|---|---|---|
| 1단계 — 주제가 없을 때 제목 15개 · 길이를 모를 때 길이 | 무엇을 만들지 정해야 함 | 「1번」「2」 |
| 1단계 — 대본 + 팩트체크 + 자가 검토 + 제목 3안 + 첫 화면 문구를 **한 번에** 보여 준 뒤 | 대본이 마음에 들어야 뒤가 의미 있음. 제목도 이때 하나 고른다 | 「좋아, 제목 1번」「○○ 문장 고쳐줘」 |
| 2단계 — 생성 직전(미리 허락 없을 때) | 글자·크레딧이 든다 | 「생성해줘」 |
| 4단계 — 비교판(「맡길게」가 아닐 때) | 스타일은 사람이 고른다 | 「A로 가자」 |

- 그 밖(3단계 문장 시각, 5단계 점검 화면·렌더, 단계 사이 넘어가기)은 멈추지 않고 이어 간다.
- 1단계 대본 확인에서 「좋아」를 받으면 script.md 를 저장하고(1단계 스킬의 「저장」) 바로 2단계로 간다.
- 멈출 때마다 맨 위에 한 줄로 어디인지 밝힌다: 「[2/5 나레이션] 생성 전 확인」.

## 끝

- 5단계가 끝나면 video.mp4 를 보내고 길이·장면 수·스타일을 한 줄로 알린다. 고칠 곳을 말하면 그 단계로 돌아가 고치고, 그 뒤 단계만 다시 한다(예: 자막 → 5단계만, 읽기 → 2~5단계).
- 각 단계 스킬의 「넘어가기 전 점검」을 그대로 지킨다. 걸리면 그 자리에서 고치고 간다.

## 하지 않는 것

- 단계 스킬의 규칙을 줄이거나 건너뛰지 않는다(팩트체크·자가 검토·점검 화면 확인 포함).
- 허락 없이 크레딧을 쓰지 않는다.
