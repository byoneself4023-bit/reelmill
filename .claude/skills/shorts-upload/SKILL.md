# 업로드 문구

youtube-agent-skill(MIT, Jake Schincariol)의 yt-package · yt-seo 생각을 한국어 쇼츠에 맞게 다시 만든 단계다. **글만 쓴다. 업로드는 사람이 한다.**

입력: `work/episodes/<폴더>/script.md` (고른 제목 · 첫 화면 문구 · 대본 · 팩트체크 출처)
결과: 같은 폴더에 `upload.md`

멈추는 곳은 한 번 — upload.md 를 보여 주고 고칠 곳을 물을 때.

`reelmill/channel.md` 를 먼저 읽는다 — 설명란·고정 댓글의 말투와 안 쓰는 말, 하지 않을 주장을 따른다.

## 1. 제목·첫 화면 문구 검사

```bash
uv run .claude/skills/shorts-upload/scripts/title_check.py --title "고른 제목" --title "후보2" --title "후보3" --screen "첫 화면 문구"
```

- 길이(40자 · 60자), 숫자·이름·날짜, 첫 화면 문구가 제목 낱말을 되풀이하는지(명사·숫자 비교), 첫 화면 문구 길이를 본다.
- 걸린 곳은 **고친 안을 함께** 낸다. 제목·첫 화면 문구를 바꾸면 영상 첫 화면도 바뀌어야 하므로, 바꿀지는 사용자에게 묻는다. 첫 화면 문구는 영상이 아니라 커버에 들어가므로, 바꾸면 script.md 「## 첫 화면 문구」를 고치고 커버만 다시 뽑는다(`make_video.py <폴더> --cover`, 몇 초).

## 2. 설명란 · 해시태그 · 태그

- **이 영상이 이겨야 할 검색어 3개**를 먼저 적는다(사람이 실제로 칠 말). 제목이나 설명란 첫 줄에 그 낱말이 들어 있는지 확인한다. 없으면 문제는 설명이 아니라 제목이다.
- **설명란 첫 두 줄**: 이 영상이 주는 것 한 줄(검색어 포함) + 핵심 숫자나 사실 한 줄. 그 뒤에 출처(팩트체크 표의 출처를 매체 이름으로), 마지막에 해시태그.
- **해시태그 3~5개.** 주제 2~3개 + `#쇼츠` 정도. 내용과 상관없는 해시태그는 쓰지 않는다(유튜브 정책 위반). 60개를 넘기면 전부 무시된다.
- **태그 15개 안.** 약한 신호다 — 맞춤법이 갈리는 말, 고유명사, 줄임말 위주로.
- **고정 댓글 한 줄**: 영상이 남긴 질문을 시청자에게 던진다(예: 「상한제, 필요하다고 보세요?」). 구독 부탁은 쓰지 않는다.
- 숫자·출처를 지어내지 않는다. 팩트체크 표에 있는 것만 쓴다.

## 3. 올리기 전 점검 (upload.md 맨 아래에 적는다)

- [ ] 대본·화면 숫자가 팩트체크 ✓ 값과 같은가
- [ ] AI 표시가 필요한가 — 실존 인물의 목소리·얼굴을 흉내 냈거나 실제 사건을 사실처럼 재현했으면 「변경되거나 합성된 콘텐츠」에 표시. 글자·도형 화면과 일반 합성 목소리(내 목소리 복제 포함)는 대상이 아님
- [ ] 출처를 설명란에 적었는가
- [ ] 커버: 5단계가 만든 `cover.png` 를 스튜디오에서 커버로 올린다(9:16, 인증된 계정 필요 — 컴퓨터에서 올릴 때나 올린 뒤에)

## upload.md

```
# 업로드 — <고른 제목>
## 제목            ← 고른 제목 (검사 점수, 걸린 곳)
## 첫 화면 문구
## 검색어 3개
## 설명란          ← 그대로 복사해 붙이는 덩어리
## 태그            ← 쉼표로 이은 한 줄
## 고정 댓글
## 올리기 전 점검
```

통과하면 사용자가 유튜브 스튜디오에 올린다.
